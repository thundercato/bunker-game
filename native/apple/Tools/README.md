# Pinned native content exporter

Run at repository root with Node.js 22 or newer; no npm dependencies or Apple tools:

```sh
node native/apple/Tools/convert_scene.mjs
node native/apple/Tools/test_pipeline.mjs
node native/apple/Tools/convert_scene.mjs --check
```

`--check` regenerates in memory and compares every generated byte. It writes no
canonical or generated content. `source-lock.json` pins the imported repository
revision and the exact canonical world, compiler, scene factories, manifests,
shared textures and notice bytes. GLB files additionally match their asset
registry SHA-256, or the explicit source lock for older manifests. Source changes
fail; updating the native source baseline requires a deliberate content review
and replacement of the lock hashes, not changing a revision label alone.

The exporter imports the existing campaign interior factory and world-document
compiler. It chooses **Forester’s cottage**, stable building ID `forester`, at
source world position `(-30, 0, -59)`, retaining its real doors, furnishings,
container bindings and 3.2 m stairs. It compiles this one building, not the full
campaign or the World Editor's terrain/road/water document. The generated
`world-document.json` records the source factory layout and placement.

A small native outdoor plane, gravel approach, five instances of the existing
EZ-Tree pine and an existing Kenney log form the bounded approach. The source
world's terrain is not ported. Three source item IDs (`med`, `water`, `wire`)
provide an explicit deterministic search fixture; this does not claim parity
with the browser's weighted seeded loot engine. A native copper coil marker sits
on the actual source table; collecting it removes the marker, never the table.

## Resource contract

`Resources/scene.json` has format `field-signal-native-scene`, version 1. Positions
and dimensions are three-element arrays in metres, Y-up; yaw is radians with
positive local +Z rotating towards world +X. **Every pose is already world-space.**
`parentID` preserves authored identity/provenance; it is not a second runtime
transform or a scene hierarchy instruction. Stable binding IDs stay unchanged.

- `objects`: `id`, `kind`, `position`, `size`, `yaw`, optional `assetID`, `parentID`,
  `doorID`, `material`. Structural pieces retain the original `kind` and authored
  parent ID. Floor Y is the **top** surface; every other object Y is its bottom.
- `colliders`: `id`, `parentID`, `position`, `size`, `yaw`, optional `doorID`.
  Collider Y is always the bottom. Use `parentID` to exempt a searched object's
  own collider from its interaction sight line. True doors retain the source
  binding; unbound authored archways remain open and omit the layout helper's
  otherwise unbound phantom door blocker.
- `stairs`: `id`, `position`, `size`, `yaw`; size Y is rise, rising towards local
  -Z. Floor pieces already contain the source stairwell cutout.
- `interactions`: source `id`, `kind` (`door`, `container`, `loose`), `objectID`,
  `name`, world `position`, optional fixture `itemID`.
- `items`: existing catalogue `id` and user-facing `name`.

`Meshes/<assetID>.json` has format `field-signal-native-mesh`, version 1,
`dimensions` and `meshes`. Each primitive has flat float `positions`, `normals`,
optional flat RGBA `colors`, triangle `indices`, RGBA `baseColor`, and
`doubleSided`. Textured primitives also have flat `uvs`, `texture` (local filename
in `Textures/`), `alphaMode` and `alphaCutoff`. The runtime fits each asset's
nominal dimensions to the object's requested dimensions, matching the browser's
explicit nonuniform furniture fitting.

The GLB reader accepts only static, embedded single-buffer glTF 2 triangle models
with supported accessors. It rejects compressed extensions, sparse accessors,
unsupported modes and invalid bounds rather than silently degrading geometry.
It bakes node transforms and normal matrices once, normalises the bottom-centre
pivot, and preserves source vertex colours/diffuse texture bytes. Other PBR maps,
animation and moving furniture assemblies are deliberately outside this slice.
Search recipes use the existing original-composite closed-pose geometry tier;
provenance distinguishes these from optional licensed-model replacements.

`Resources/provenance.json` records author, source, licence, source SHA-256,
modifications, triangle counts and dimensions per imported asset. Original
third-party notices live in `Resources/Licences/`. No downloading, scraping or
new asset acquisition occurs during regeneration.
