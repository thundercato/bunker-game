Left click selects. Right-drag orbits, middle-drag pans and the wheel zooms. Drag the coloured arrows, rings or scale handles to edit a selection. Use Top for a plan view.

W / E / R select move, rotate or scale. F focuses the selection. G toggles snapping. Cmd/Ctrl+D duplicates a decorative object. Delete removes it. Cmd/Ctrl+Z undoes and Shift+Cmd/Ctrl+Z redoes. Space starts or exits the walk test.

Stairs and upper floors share their layout data. Moving or resizing stairs automatically moves the opening in the floor above. Set the stair rise to the upper floor height.

Searchable cupboards and tables with loot keep their existing game IDs. You can move them, but cannot delete or duplicate them. New props are decoration, not new loot containers.

Save draft saves locally. Export JSON creates a portable file. Test in game opens an isolated preview campaign using this layout. It does not change your normal campaign or publish to GitHub. Send approved JSON files back for a tested permanent update.

Editor v1 covers the 37 exterior buildings. Refuge, caves, free terrain editing and direct GitHub publishing are not included. Layout checks flag common problems, not every possible bad design.
