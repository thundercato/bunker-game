# Changelog

## 9.0.0 · Dead Air

- Migrated Field Signal from temporary hosting to the existing `bunker-game` repository, with the old project retained on an archive branch.
- Added the original calmer refuge track **Relay Lanterns**, and reduced the base's drone contribution.
- Added fifteen classified dossiers using true destination images and marked game maps, sequential radio offers, NPC-specific jobs and a completed-operation archive.
- Switched simulation from action-only to continuous base/field clock rates, while keeping menus and background states paused.
- Expanded the map with a crossable river, road/rail bridges, additional buildings, pylons, fortified compound, rear breach and sewer alternatives.
- Added physical vault stair transitions and fixed a scheduling bug that could prevent the transition firing.
- Added humanoid mist riflemen, vision/torch/building rules, impact decals, hit flashes, knife swings and secondary tool modes.
- Added licensed equipment meshes and a boombox-style music receiver with a three-track crackly playlist.
- Added optional, truthfully reported haptic tests rather than pretending unsupported devices vibrate.
- Hid anomalies until probe contact, retained reveals through an expedition, and reset them on returning to base.
- Preserved compatible earlier campaigns through validated migration, without inventing old completion timestamps.
- Removed duplicated rifleman hit geometry during testing and preserved simulation time debt through queued worker updates.

## 8.0 · Stillwater

Recovered and preserved as the migration baseline: controller preflight/Clinic, scene placement cleanup, wall/road overlap reduction, image filtering, route guidance, field journal and photo mode.

## 7.0 and earlier

The playable game's history before GitHub migration is described in the preserved asset-credit and source records. The retired Godot/Phaser Bunker Game is a separate project, not an earlier Field Signal version.


## 10.0.0 · Fieldcraft

Added 25 imported CC0 model families, 61 item previews/inspection models, shared inspector, item catalogue, full-screen interactive atlas and current-mission shortcuts. Replaced 53 tables, 131 searchable furniture visuals and 14 bed frames; added imported cladding, frames, cornices and outdoor props. Retained the v9 save schema/storage and calm refuge soundtrack. Added pure map tests, item coverage validation, real gesture tests and additional browser regression checks.
