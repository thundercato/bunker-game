# Field Signal World Editor

See [the complete editor guide](WORLD_EDITOR.md) for current controls, save/export behaviour, safe previews and limits.

The editor is at https://thundercato.github.io/bunker-game/editor/ . The game remains at its normal address. Cmd/Ctrl+S saves a local draft; **Export JSON** downloads a portable backup. There is no automatic GitHub publication or lossless import of every v11 decoration. Approved exported layouts need integration and testing before they replace the public game.
